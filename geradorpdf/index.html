Gerador de Apostilas Das aulas do YouTube ao PDF diagramado

1 Curso

2 Aulas do YouTube

Cole o link de cada aula — só isso já basta: ao gerar, o site extrai as transcrições sozinho. Use as caixinhas pra marcar quais aulas entram na apostila. Se um vídeo não tiver legenda, abra “colar manualmente”.

3 Sugestões de temas

Peça sugestões com base nas aulas — clicar numa sugestão preenche o tema de um volume "Guia temático" do passo 4.

4 Gerar apostilas

Monte quantos volumes quiser — até vários de um vídeo só. Tipos: Insights (1ª aula marcada), Guia temático (você define o tema) e Manual completo (todas as aulas marcadas).

Configurações

Avançado — usar sem backend

O normal é publicar este site no Cloudflare Pages com a variável ANTHROPIC_API_KEY (veja o README). Se você estiver rodando o site sem backend (ex.: GitHub Pages), pode colar sua chave aqui — ela fica salva somente neste navegador.

Pedido pronto!
